Privacy Policy

Last updated: November 11, 2026.

Backups is a personal utility operated by its owner. It uses Google's Drive API through rclone to create, list, read, update and delete backup repository files that this application creates or that the owner explicitly authorizes it to access. It requests the drive.file permission rather than access to all files in Google Drive.

Restic encrypts backup contents and backup file metadata on the owner's server before upload. Google Drive stores encrypted repository data and associated Drive metadata. The owner can download and decrypt backups for recovery.

Google authorization credentials and the backup encryption password are stored in permission-protected files on the owner's server. These credentials are not published on this website. The utility does not sell Google user data, use it for advertising, or intentionally share it with other parties. Google processes data as the storage and authorization provider.

Backup data remains in the owner's Drive until the owner removes it through backup management or Drive. The owner may revoke the application's authorization in Google Account settings; revoking authorization does not itself delete existing backups.

This information website has no login form, added analytics or advertising. GitHub Pages hosts it and may process visitor request information under GitHub's privacy practices.

Only the owner uses this utility. Privacy questions and deletion requests are handled directly by the owner through the support email displayed on Google's consent screen.
